🚀 Overview
This project presents a data-driven framework to measure and analyze multidimensional socioeconomic deprivation across districts of Karnataka, India. It integrates statistical modeling, spatial analysis, and a decision support system (DSS) to support evidence-based policymaking and regional planning.

🎯 Objectives
Construct a Socioeconomic Deprivation Index (SEDI) using multidimensional indicators
Identify regional disparities across districts
Detect spatial clustering using spatial econometric methods
Develop a Decision Support System (DSS) for policy recommendations
Enable scenario-based analysis for planning interventions

🧠 Methodology
1️⃣ Data Collection
Census of India
NITI Aayog SDG Index
Karnataka Economic Survey
2️⃣ Indicator Processing
Data validation (missing values, outliers, consistency)
Min-Max normalization (0–1 scale)
3️⃣ Index Construction
Domain-based aggregation:
Economic (30%)
Education (25%)
Health (20%)
Infrastructure (25%)
Final Index:
SEDI (0–100 scale)
Higher score → Lower deprivation

📊 Key Features
📌 Socioeconomic Index (SEDI)
Measures district-level development
Enables ranking & comparison
📌 Statistical Analysis
Descriptive statistics
Correlation analysis
PCA for dimensionality assessment
📌 Spatial Analysis
Global Moran’s I → detects clustering
Local Moran’s I (LISA) → identifies hotspots & outliers
📌 Decision Support System (DSS)
District-level profiling
Sectoral deficit identification
Policy recommendation engine
Scenario simulation (what-if analysis)

🗺️ Key Results
SEDI Range: 0.34 – 94.34
Strong spatial clustering detected (Moran’s I > 0)
High deprivation clusters: Northern Karnataka
Low deprivation clusters: Coastal & urban regions

💡 Use Cases
Government policy planning
